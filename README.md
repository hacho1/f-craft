# F-Craft · F급의 나날

Minecraft Java의 기존 Forge 프로필을 확장한 **RPG 모드팩 패치**입니다. 전투와 생활 직종을 키우며 NPC 의뢰를 풀고, 새 지역을 탐험하는 흐름을 구현했습니다. 현재 공개 소스는 **v11.0**입니다.

## 주요 기능

- **12직종 승급** — 퀘스트와 실기 시험으로 직종을 성장시키고, 오른쪽 HUD에서 다음 목표를 확인합니다.
- **NPC 의뢰·퀘스트북** — 머리 위 의뢰 표시와 진행 상태별 아이콘으로 새 의뢰와 완료 가능 항목을 구분합니다.
- **본토 탐험·비석** — 본토 다섯 지역, 도항 해금, 직접 방문한 비석 사이의 이동을 연결합니다.
- **개인 군마·파티 클레임** — 성장 등급을 반영한 군마를 호출하고, 파티 인원에 따라 점유 한도를 적용합니다.

## 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 게임 환경 | Minecraft Java 1.20.1 · Forge 47.4.28 · Java 17 · CurseForge 프로필 |
| 게임 로직 | KubeJS(JavaScript) · Java Forge 브리지 · FTB Quests |
| 리소스·검증 | JSON · SNBT · Minecraft 리소스팩 · Python 설치·검증 도구 |

## 실행 방법

1. CurseForge에서 **Minecraft Java 1.20.1 / Forge 47.4.28** 기반의 기존 **F급의 나날** 프로필을 준비합니다. [모드 목록과 버전](수정파일/modpack_manifest_1.20.1_forge.json)
2. 게임을 종료하고 프로필을 백업한 뒤 가이드에 따라 `수정파일/`의 패치를 기존 프로필에 적용합니다. Waystones 14.1.21과 Balm 7.3.44는 서버와 클라이언트에 각각 설치합니다. [설치·검증 가이드](설치_검증_가이드_v11_0.md)
3. 프로필을 실행하고 **O**로 승급 HUD를 열어 봅니다. 직종 등록 후 **F8**로 개인 군마를 호출할 수 있습니다.

GitHub에는 패치 소스와 리소스가 들어 있습니다. 실행에는 기존 프로필과 모드 의존성이 필요하며, 월드와 플레이어 세이브는 별도로 관리합니다.
