# F-Craft · F급의 나날

Minecraft Java 1.20.1 / Forge 47.4.28용 RPG 모드팩의 v11.0 작업본입니다. 12직종 승급과 퀘스트 HUD, NPC 의뢰 아이콘, 본토 지역과 비석, 개인 군마를 포함합니다.

- [모드 목록 및 버전](수정파일/modpack_manifest_1.20.1_forge.json)
- [개인 적용 패치 다운로드](https://drive.google.com/drive/folders/1SJ_hI2xfz4kv5BanE60rAaFfzL3wp_-H)

패치는 CurseForge의 기존 F급의 나날 프로필을 기준으로 합니다. GitHub에는 패치 소스와 리소스를 보관합니다.
